# 本次论文的总体技术路线图实例

第三版是最终整合论文采用的路线图。[PNG 预览](roadmap-final.png)便于浏览，[Excalidraw 源文件](roadmap-final.excalidraw)可查看和调整元素位置。它以四个错位区域承载四问，混合短方法流程和 17 张本论文的实际结果图，并将问题四的分区求解放在左侧流程、三项结果放在右侧。

此图说明了怎样按本研究的四问关系选择模块和证据；图中的地理、运输和资源结果不属于可迁移模板。源文件嵌入真实图件，部分新标签以字形路径保存，可以移动和缩放，但不能双击直接改字。原工程另有生成代码与来源哈希记录；本发布实例不依赖那些本机字体路径和题目数据运行。

使用 Excalidraw MCP 导入和回读本实例的结果见 [检查记录](verification.md)，原生导出效果见 [MCP 预览 PNG](roadmap-mcp-preview.png)。

本例的画布尺寸、颜色、模块数量和图件数量来自当时用户确认的参考图。新论文应先决定内容关系，再采用适合自身题目与纸面宽度的布局。缩小整图时还要重新检查内嵌图的轴字与图例。
