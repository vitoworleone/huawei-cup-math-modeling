# 第三版实例的 MCP 回读检查

2026-09-28，以本目录的 `roadmap-final.excalidraw` 为输入，调用 Excalidraw MCP 的 `read_diagram_guide`、`describe_scene`、`import_scene(mode="replace")` 和 `export_scene`，导出到工作区核验目录并与原文件比较。随后连接本地浏览器画布，使用 `set_viewport`、`get_canvas_screenshot` 和 `export_to_image` 做原生渲染检查，保留 [MCP 导出 PNG](roadmap-mcp-preview.png)。

| 检查 | 结果 |
|---|---|
| 元素 | 导入与回读均为 162 个：51 矩形、4 线段、85 图片、20 箭头、2 菱形；全部元素 ID 保留 |
| 图片 | `files` 中 85 个资源均保留，85 个图像元素均能找到资源；图像数据逐项相同 |
| 几何与内容 | 回读后位置、尺寸和其他原有字段无变化；MCP 增加了 `index`、部分 `roundness` 和 `elbowed=false` 字段。`roundness` 可能影响外观，所以又做原生截图核验 |
| 整图 | 第三版原始 PNG 缩至约 756 像素宽后，四问分区、流程及结果图位置仍清楚；小图内的细轴字和数字不足以承担独立读数，相关定量解释应回到正文原图 |
| MCP 原生截图与导出 | 已完成：本地画布前端连接后，四问分区、标题、图件和箭头完整，无明显重叠或裁切；原生 PNG 为 1352×1120，含页面外白边，与原生成图 3996×3300 不要求逐像素一致 |

回读中的工具总边界为 1332×1224，但唯一越过 1100 的记录是 `route_v3_150` 箭头外框；它的局部 `points` 向上延伸，实际线段仍在画布内。不能据该总边界误判裁切。

这一轮验证了第三版实例在 MCP 导入、回读和原生渲染时的结构完整性。原始第三版 PNG 仍是论文使用的高分辨率样张，MCP 导出 PNG 是画布显示验收件。之后用此 skill 制作新图，仍需检查新图自己的正文证据和实际纸面预览。
