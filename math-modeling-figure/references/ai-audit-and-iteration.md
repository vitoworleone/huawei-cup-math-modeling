# 图件 AI 审计与迭代规范

这份规范从本次四题绘图过程的 `PLAN.md`、`REVIEW.md`、`HANDOFF.md`、逐图问题记录、数据指纹与 PNG/PDF/SVG 核验 trace 提炼。它用于新图初审、旧图局部修改和整套图集复核。审计轮数由未关闭的问题决定，不预设“四轮”或固定重画次数。

## 1. 建立可审计基线

开始前列出当前正文实际引用的图号、文件路径、插入宽度和图注；记录绘图脚本、输入数据、计算结果及现有三格式文件的版本或 SHA-256。确定哪张旧图是当前正式版、哪张只是视觉样例，写清本轮允许改变的项目。若只改字体、标签、留白或配色，冻结模型结果、坐标点、阈值和其他非目标图。

把旧版保留在历史目录或版本控制中。新图先写到暂存位置，核查通过后再提升为正式图；避免全量旧脚本覆盖已经局部修好的图。没有匹配当前方案的数据时登记“待实验”，不凭视觉需要补造曲线或结果。

## 2. 先审计，再修改

AI 审计要逐图检查四类问题，并给出能复核的证据；只说“看起来不协调”不足以直接改图。

| 类别 | 必查内容 | 可定位证据 |
|---|---|---|
| 科学内容 | 数值、单位、颜色编码、点位、阈值、任务编号与冻结结果一致；图注没有把示意或预留能力说成实测/实际执行 | 图号、数据字段、源文件、结果记录、图内位置 |
| 视觉表达 | 字体和字重、轴名与刻度、图例、色条、面板间距、标签遮挡、裁边、颜色对比；按论文插入宽度判断 | PNG/PDF/SVG 渲染图、纸面尺寸、边界框或截图 |
| 文件与格式 | 三格式对应同一版本；PNG 有效 DPI、PDF 字体嵌入及实际渲染、SVG 独立渲染；图注、编号和审阅页链接正确 | 导出记录、文件哈希、渲染结果、链接检查 |
| 正文衔接 | 当前 LaTeX/Markdown 引用的是已核验图；图前后解释与图示一致，图题和纸面宽度正确 | 正文引用行、最终 PDF 页面 |

对每项问题使用稳定 ID，记录：图号、观察、证据、预期规则、允许修改范围、修复动作、复核结果和状态。可复制[图件审计记录模板](../assets/audit-trace-template.md)。状态至少区分“待修复”“待复核”“内部通过”“待实验”“用户待审阅”“用户已确认”；一次导出成功不能直接标为后两项。

## 3. 按问题局部迭代

1. 先核对问题是否真实存在于**当前正式图**，以及规范是否仍有效。旧样例只提供样式时，不把旧数据迁回新图。
2. 记录修改前图件、代码与数据指纹。针对图号局部改绘；若多图共享样式配置，列出可能受影响的图号。
3. 导出 PNG/PDF/SVG，核对数据与结果。数值和几何未授权变化时，检查输入指纹和绘图数据一致；代码中不得手改源数值掩盖差异。
4. 按实际纸面宽度检查字体、线宽、间距、单位、标签、色条和边缘。PDF 要真正渲染并检查字体，SVG 要独立渲染；网页审阅页保持固定论文宽度，浏览器整页及局部都要看。
5. 用哈希或等价证据确认非目标图没有变化。更新图注、清单、正文引用、审阅页、问题状态和交接记录；复审发现新问题时新增 ID，不覆盖原发现。

一个问题的关闭条件是：修复后文件可定位、所要求的数据和视觉核验通过、非目标图范围清楚、审阅页或正文当前指向新文件。缺少其中任一证据就保持“待复核”。用户已批准样例，只表示样例获认可；整套新导出图仍需单独记录验收状态。

## 4. 交付时留下的最小 trace

| 文件或记录 | 要保留什么 |
|---|---|
| `PLAN.md` | 图号范围、数据/样式基线、允许改动、待办与依赖 |
| `REVIEW.md` | 逐图数据、字体尺寸、PNG/PDF/SVG 和正文纸面的审计结果；未检查项明确写出 |
| `HANDOFF.md` | 按时间追加的发现、修改、复核及未解决问题；注明哪段是历史状态、哪段是当前状态 |
| 图件清单 | 稳定图号、图注、源码与数据来源、三格式路径及哈希、成稿宽度 |
| 审阅页与证据 | 固定论文宽的新旧对照、PDF/SVG 渲染、必要的测量值及浏览器截图 |

小型单图任务可以合并为一份记录，但上述来源、问题、改动、证据、状态仍须能追溯。交付时分别报告机器检查、AI/人工目视复核和用户确认，不把一种检查替代另一种。

## 5. 本次 trace 所示的具体教训

- 问题二 V91/V92：移动地图标签后又发现靠近轴或被航线穿过，因此每次局部修复都要重新看实际 PNG/PDF；真实点位和路线未移动。
- 问题二 V93：固定 180 mm 的审阅图在窄窗口被裁切，修的是审阅页换行，不通过缩图改变论文字号；图件哈希保持不变。
- 问题二 V94：只复用公共样式文件仍漏掉旧绘图入口里的间距默认值，且一律设 180 mm 丢失不同图型的宽度分工；必须量测**实际导出**纸面规格。
- 问题三三维间距：按投影轴和可见地形量净距，修标签与留白后检查视角、航迹和数据没有变化。
- 问题二图 5-2 与第五章专项：流程框图、路线矩阵、余量图和 SOC 图先在暂存位置核验，再更新正式三格式，并在最终章节 PDF 中复看。
