# 绘图规范来源与优先顺序

本次按整个数学建模工作区的 Markdown 文件名与内容检索了绘图、图表、图片、图注、尺寸和审阅记录；重点核对 `论文撰写`、`D题`、`docs/数学建模Skill图表增强版`，再以成品 LaTeX 的章节引用确定实图。下表是可复用规范的来源地图，不把历史清单中的“最终版”字样直接当成当前成品。

## 使用顺序

1. **当前成品实际引用**：`draft/D题/sections/ch4.tex` 至 `ch7.tex` 的 `\paperfigure` 路径、图题和宽度；`draft/D题/figures/` 是其实际 PDF 图件。整合版 `论文撰写/正文/整合版/排版/章节/` 也记录原始图名。两个工程中的 PDF 文件字节可能不同，选成品示例时采用前者实际引用的文件。
2. **用户确认的总规范**：`论文撰写/论文图片绘制与优化规范.md` 是内容、图注、配色和导出总则；`论文图片字体与间距统一规范.md` 的 v1.5 更新二维字体和距离；`论文三维图片字体与间距规范.md` 的 v1.6 更新三维投影轴、图例与留白。后两份与总规范旧参数冲突时按更新版。
3. **章节专项修订**：`论文撰写/正文/第五章_问题二模型的建立与求解/第五章图表专项问题清单与调整思路.md` 及问题二 `定稿图集/图注与尺寸.md`、`REVIEW.md` 记录 2026-09-26 的紧凑排版、重绘和局部字体处理。第三章 `图表/Excalidraw配置与出图说明.md` 给出流程框图的白底、直角框、黑色箭头和淡色分工。专项修订只覆盖对应图件；正文实际插入宽度仍以最终 LaTeX 为准。例如问题二图集的 Q2_F03 记录 150 mm，成品第 5 章引用为 160 mm。
4. **各图特定约束和证据**：四题 `论文撰写/问题一…四/定稿图集/` 中的 `图注与尺寸.md`、`文件清单.json`、`REVIEW.md`、`HANDOFF.md` 与 `图片审阅.html`，说明图内/图外信息、数据口径、当前取图入口及哪些调整经过检查。`论文撰写/定稿图集导航.md` 汇总四题 11/12/11/5 组图。
5. **选图参考和历史记录**：`docs/数学建模Skill图表增强版/02_高级图表库/` 提供图型备选，`D题/问题一` 和 `D题/问题二` 的图表修订说明解释过程；`论文撰写/历史规范/`、各题 `历史版本/`、`定稿版_20260925/` 及旧稿用于追溯，不覆盖已确认的当前规范。`论文撰写/四题图片字体与间距问题清单.md`、`图片字号与布局问题清单_20260925.md`、`三维图片间距修订清单.md` 和各章节图表检查清单是问题与执行记录，需结合后续 REVIEW/HANDOFF 判断是否已解决。

## 通用化后的规则

- 图型由数据关系决定：矩阵比较用热图，连续约束用曲线，离散方案变化用阶梯，资源占用用时间轴，空间关系才使用地图或三维。
- 先确定正文位置、图要证明的结论、数据源与版本、图号和成稿宽度。图内留轴、单位、图例及短标签；长口径和完整数值放图注、正文或表格。
- 本次科学数值图的中文为微软雅黑，西文和数字为 Times New Roman；成稿普通字基准 5.973632 pt。源画布字号随实际缩放计算。二维按 1/2/3 mm 的刻度、轴名、图例净距复核；三维按投影轴外法向检查。流程框图须结合其专项视觉基准独立排版。
- 相同颜色应指向相同变量或类别；颜色、格内数字、色标和单位必须一致。不可行、缺失、零值分开表达，真实空间坐标和离散阈值不因美观而改动。
- 输出 PNG/PDF/SVG 后，在 LaTeX **实际插入宽度**下检查可读性、字体、线条、裁切和图题位置。图集建议宽度和 HTML 预览宽度不能替代成品页检查。
