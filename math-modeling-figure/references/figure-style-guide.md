# 数学建模论文绘图规范

本规范提炼自本次 D 题的《论文图片绘制与优化规范》、二维字体与间距 v1.5、三维间距 v1.6，以及四题定稿图集的图注、源码和核验记录。另有第五章 2026-09-26 专项修订与第三章流程图的局部样式，见[规范盘点](source-priority.md)。下面的数值是此次定稿的**默认基准**，新比赛、期刊或用户新确认的样例可替换它们。

## 1. 先决定图要说明什么

每张图先写一句可验证的用途，再指定数据来源、变量、单位、论文段落与图注。优先选择让读者直接看见关系的图型：连续响应用曲线，离散跳变用阶梯，矩阵比较用热图，航线与地形用地图、剖面或三维，资源占用用甘特图。三维只在空间关系确实需要时使用，并检查透视是否妨碍定量比较。

数据图、方法示意图和外部参考图应分清来源。示意图的几何和标记不能被误认为计算结果；外部图可借鉴表达，不能替换自己的数值证据。没有数据支撑的实验曲线不补画。

| 要说明的关系 | 可用图型 | 画前必须核对 |
|---|---|---|
| 节点、地形与路线 | 等比例地图、航段高程剖面；空间遮挡需要时用三维 | 坐标系、地形分辨率、真实点位、净空口径 |
| 机型与服务区的二维组合 | 同尺度热图或矩阵 | 颜色和格内数字是否同量、色标单位和范围 |
| 载荷、能耗与约束边界 | 曲线加预算线、可行域 | 单调性、阈值、可行端点，不能把超限画成零 |
| 参数变化导致离散方案切换 | 阶梯图 | 精确变化点、区间开闭、不可行区域 |
| 飞机、电池或中继资源占用 | 甘特图或时间轴 | 同一资源不能重叠、时间单位、任务编号映射 |
| 多方案结果与权衡 | 并列图、Pareto 图或结果表 | 指标方向、共同基准、差值与完整数值来源 |

上表是选图起点；已有通过审阅的图型可继续保留。不能因为想让全篇图型“多样”而改用不适合数据的图。

## 2. 图、图注、结果表的分工

| 位置 | 应放内容 |
|---|---|
| 图内 | 轴与单位、必要刻度、颜色含义、短面板标题、少量关键点或阈值 |
| 外部图注 | 条件、符号与颜色规则、关键口径、端点是否可取 |
| 结果表或数据文件 | 完整编号、全部精确值、逐箱或逐架次明细 |

不在图幅顶部和底部重复铺陈长段解释。若删去图内文字，须确认单位、色标和读图必需的含义仍在。图前由正文引入，图题在图下，图后讨论观察结果与限制；图与图题保持同页。本次论文正文宽 160 mm，插图按内容选择 120、140、160 mm 等宽度，等比缩放，不能超过正文宽。

## 3. 本次定稿的视觉基准

- 中文 Microsoft YaHei；英文、数字和单位 Times New Roman。普通图内文字为 normal，批准使用的短总标题及子图标题同号、真实 bold。找不到字体时明确报出，不能静默换成宋体、黑体或伪粗体。
- 成稿纸面普通文字与标题基准为 **5.973632 pt**。这是此次参考源图 9.5 pt 经缩放后的纸面字号，不是任何新画布都直接填 9.5 pt。可直接按最终物理尺寸建画布并使用 5.973632 pt；若从大画布缩小，则按实际宽度换算源字号。数学上下标按数学语义保留。
- 这套字号针对已确认的科学数值图。第三章、第五章经专项修订的流程框图采用白底、黑色直角边框和箭头、淡色角色区分，成稿文字按实际框图排版单独验收；不能为了满足数值图字号而把流程图字压小。成品论文中具体图宽以正文 LaTeX 的 `\paperfigure` 参数为准，图集早期的“建议宽度”仅作起点。
- 可见 X/Y 轴线成稿约 **0.754564 pt**，刻度线约 **0.503043 pt**，轴线同宽同色。热图或矩阵可取消无用刻度短线，不为套样式硬加边框。
- 黑字和足够对比度优先。蓝 `#2056A0`、红 `#D83A46`、青绿 `#418775` 是本次工程的已确认色值；颜色必须绑定明确变量或类别。红色不全局代表风险。连续非负热图曾用 `Blues`，但需按变量与数据范围指定色标。
- 相同类别跨图保持同色；若颜色仅标类别，数值仍由标签或几何长度表示。黑白打印有区分需求时加线型或标记。零值、缺失、不可行分别编码。

## 4. 纸面间距

二维适用图型在完成字体解析后，按最终插入宽度测量文字边界框：

| 关系 | 目标净距 |
|---|---:|
| 轴线或类别边界到刻度文字 | 约 1 mm，容差 ±0.5 mm |
| 刻度文字最外缘到轴名称 | 约 2 mm，容差 ±0.5 mm |
| 底部轴名或刻度到外置图例 | 约 3 mm，容差 ±0.5 mm |
| 外置图例到底部画布边缘 | 约 3 mm，可在 2.5—5 mm 内 |
| 短标题到最近绘图内容 | 约 2.5 mm，先确保无遮挡 |
| 相邻面板的完整内容 | 至少 3 mm |

这些距离按文字与符号的实际可见边界判断；图例边框的空白 padding 不应冒充内容距离。轴名在同列子图中按最宽刻度组对齐。先改位置、间距、图幅比例和重复文字，最后才考虑字号；不靠缩字或移动真实数据点解决碰撞。没有轴或图例的图，相应项目记为不适用。

三维图沿固定视角下投影轴的外法向量刻度与轴名距离：刻度到轴线约 1 mm，轴名到刻度组约 2 mm；顶部图例到可见图形、底部轴名到外置图例约 3 mm。不要用三维 axes 的不可见立方体角点测留白，也不要为满足间距改变航迹、地形、视角或坐标范围。

## 5. 结果必须保持科学含义

- 曲线、点位、阈值和约束来自源数据；若排序为阅读而变化，保留到稳定编号的映射。
- 离散变化画阶梯，不平滑成连续；不可行区间单独标记，不补零连线。端点开闭须与模型一致。
- 颜色、数字和色标必须编码同一变量；不同量或不同尺度不能无说明地共享颜色。
- 图中可用适度四舍五入，精确数值留在结果表。复合图每个面板应分别承担证据作用，避免重复展示相同数据。
- 对旧图做排版修改时，记录原文件与新文件；未重跑的历史实验不能写成这次重新计算。

## 6. 导出与验收

绘图脚本、原始或冻结结果、三格式图件、图注和核验记录分开存放。通常输出 PNG、PDF、SVG：PNG 在最终插入宽度下有效分辨率至少 300 dpi；PDF 核对页面物理尺寸与字体嵌入；SVG 独立打开检查字形与裁切。栅格地形可以嵌入矢量容器，不能仅凭 `.pdf` 后缀声称全图为矢量。

用论文的实际插入宽度渲染审阅，并分别记录：①数据与结果一致；②格式与文件可用；③目视布局可读；④用户是否确认。程序成功和自查通过不等于用户已认可。批量改图先列旧图覆盖表，更新稳定图号、图注、预览及清单；旧版进入历史目录，避免重跑时覆盖当前版。
