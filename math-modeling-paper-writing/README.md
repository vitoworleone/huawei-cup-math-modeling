# Math Modeling Paper Writing

一套供 agent 使用的中文数学建模论文写作与审阅 skill。它把本次数模论文中实际使用的正文规划、完整初稿、模型审查、论证修订、学术表达、中文通读及全文收束方法整理到同一入口。

| 文件 | 用途 |
|---|---|
| `SKILL.md` | 选择结构讨论、起草、审阅或修订工作方式 |
| `references/composition.md` | 从题目、模型、结果和图表构建正文 |
| `references/review-and-revision.md` | 内容、论证和语言的审阅次序 |
| `references/whole-paper.md` | 摘要、文献用途、各章整合和重复解释精简 |
| `references/trace-derived-patterns.md` | 从实际写作 trace 提炼的判断实例 |
| `assets/work-record-template.md` | 可选的起草与审阅记录模板 |

将整个目录放进所用 agent 的 skills 目录即可使用。可以请求“先讨论某章结构”“按确认的模型与结果写第一版”“审查这章的模型与结论范围”“按审查意见修订正文”等。用户只要求审阅时，skill 不会自行写终稿。

## 提炼来源

本 skill 以本次数模比赛的章节撰写思路、第一版说明、审查记录和最终正文为实践依据，并参考当时实际使用的 `research-writing-skill`、`mm-paper-reviewer`、`academic-humanizer`、`humanizer-zh` 的职责划分。这里重新写成独立规则，没有复制这些 skill 的说明或其附带材料。原项目中的固定轮数、图数、具体算法和数值不作为通用要求。

图件绘制可使用单独的 `math-modeling-figure` skill；LaTeX 页面样式可使用 `latex-paper-template`。本目录不包含本次比赛的完整论文、数据、代码或外部参考论文。
